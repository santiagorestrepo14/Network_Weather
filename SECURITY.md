# Security / Seguridad

Network Weather runs without administrator privileges and keeps history on the local machine. Imported images are decoded as images only; the application never executes them. TLS certificate validation remains enabled.

If you find a sensitive vulnerability, do not include exploit details or private data in a public issue. Once the GitHub repository is created, use its private security reporting channel if enabled. Until then, contact the repository owner directly through a channel they provide.
