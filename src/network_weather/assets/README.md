# Weather artwork

These eight original background illustrations were generated for Network Weather from project-specific prompts. They contain no interface text or metrics. Qt renders moving rain, lightning, wind and fog independently so users can replace the backgrounds without losing effects.

Los ocho fondos originales se generaron para Network Weather a partir de descripciones propias del proyecto. No contienen texto ni métricas. Qt dibuja lluvia, relámpagos, viento y niebla por separado para que se pueda cambiar el fondo sin perder los efectos.
