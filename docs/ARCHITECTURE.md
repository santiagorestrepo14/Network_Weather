# Architecture / Arquitectura

`probes.py` performs DNS, TCP and HTTPS checks without changing network settings. `windows_network.py` reads Windows IPv4 gateways with a five-minute cache and checks ICMP echo without parsing localized ping text. `wifi.py` reads optional connected-radio quality through Native Wi-Fi without SSID/BSSID queries. `collector.py` groups actual probes into a round and records local adapter snapshots. `metrics.py` computes protocol- and destination-specific statistics. `weather.py` classifies a rolling window using explicit evidence and two-candidate hysteresis. `history.py` stores rounds and incidents in SQLite. `monitor.py` coordinates those components. `desktop.py` keeps this monitor in a `QThread` so the Qt event loop remains responsive. The visual demo mode never starts the monitor.

`probes.py` hace comprobaciones DNS, TCP y HTTPS sin modificar la red. `windows_network.py` consulta la puerta de enlace IPv4 de Windows con caché de cinco minutos y comprueba eco ICMP sin interpretar texto localizado. `wifi.py` lee la calidad opcional de radios conectadas sin consultar SSID/BSSID. `collector.py` reúne sondas reales y adaptadores locales. `metrics.py` calcula estadísticas por destino y protocolo. `weather.py` clasifica una ventana temporal con evidencias e histéresis. `history.py` guarda rondas e incidentes en SQLite. `monitor.py` coordina estos componentes. `desktop.py` ejecuta el monitor en un `QThread` para no bloquear Qt. El modo demostración no inicia el monitor.

The event loop does not call network probes or SQLite. A separate `HistoryQueryThread` opens a read connection with WAL mode, queries time ranges and incidents, and sends results to the UI. `history_chart.py` draws categorical weather segments and numeric TCP latency bins independently. `incident_view.py` formats persisted incident evidence without assigning an unsupported cause. Settings and custom images live under `%LOCALAPPDATA%\NetworkWeather`. Synthetic demo visuals are not written to the measurement database.
