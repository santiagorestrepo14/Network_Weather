# Contributing / Contribuir

Open a focused issue or pull request describing the observed behavior and the intended change. Keep network measurements separate from Qt widgets. Include tests for new classification rules, probe error paths and persistence changes. Do not add repair actions or transmit local history. Run `python -m pytest` and `python -m ruff check .` before proposing a change.

Abre un issue o pull request concreto que describa el comportamiento observado y el cambio propuesto. Mantén las mediciones separadas de la interfaz Qt. Añade pruebas para reglas de clasificación, errores de sondas y cambios de persistencia. No añadas reparaciones automáticas ni envíes el historial local. Ejecuta `python -m pytest` y `python -m ruff check .` antes de proponer cambios.
